🧠 NeuroVital

Smart Health Monitoring & Risk Analysis System

---

📌 Project Overview

NeuroVital is an advanced smart healthcare monitoring system developed using C++. The system helps users monitor their daily health activities, analyze symptoms, calculate health risks, and receive intelligent health suggestions.

This project combines healthcare, smart monitoring, automation, and intelligent risk analysis into one integrated platform.

The main goal of NeuroVital is to promote healthier lifestyles through smart health analysis and preventive healthcare monitoring.

---

🚀 Features

🔐 Secure Login System

- User registration system
- Username and password authentication
- Personalized dashboard access

---

💧 Water Intake Tracker

- Tracks daily water consumption
- Provides hydration notifications
- Reduces health score if hydration is low

---

😴 Sleep Tracker

- Monitors daily sleep hours
- Detects unhealthy sleep schedules
- Gives sleep improvement recommendations

---

💊 Medicine Reminder System

- Stores medicine name and timing
- Helps users maintain medication schedules

---

🩺 Symptom Checker

The system analyzes symptoms such as:

- Fever
- Headache
- Cold
- Tiredness

Based on the symptoms entered by the user, the system updates the health score intelligently.

---

❤️ Heart Rate Monitoring System

- Monitors heart rate (BPM)
- Detects abnormal heart rate conditions
- Provides intelligent analysis and warnings

---

⚖️ BMI Calculator with Health Analysis

- Calculates Body Mass Index (BMI)
- Detects:
  - Underweight
  - Normal Weight
  - Overweight
  - Obesity
- Gives health-related suggestions

---

🚨 Emergency Alert System

If the user's health score becomes critically low:

- Emergency alert activates automatically
- Warns the user immediately
- Simulates healthcare emergency notification system

---

📊 Health Risk Analysis System

The system categorizes user health risk into:

- LOW Risk
- MEDIUM Risk
- HIGH Risk

Provides warning messages for critical conditions.

---

💡 Smart Health Tips

The system provides personalized suggestions based on:

- Water intake
- Sleep schedule
- Health score
- User condition

---

💬 Smart Health Chatbot

Interactive healthcare chatbot that answers questions related to:

- Fever
- Cold
- Stress
- Sleep
- Headache
- General health guidance

---

📈 Daily Health Report

Generates daily health condition summaries based on user data.

---

🗂️ User History Management

- Saves user data into a text file
- Stores health reports and monitoring history
- Helps maintain healthcare records

---
